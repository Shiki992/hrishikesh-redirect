# hrishikesh.vedantam.co

Redirects `hrishikesh.vedantam.co` (any path) to the main site at https://vedantam.co, which lives in [Shiki992/website](https://github.com/Shiki992/website).

GitHub Pages serves one custom domain per repository, so this repo exists only to hold the second domain. `index.html` and `404.html` are the same redirect page, so deep links keep their path.

DNS at the registrar: `CNAME hrishikesh → shiki992.github.io`.
